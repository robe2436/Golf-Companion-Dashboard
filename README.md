# Golf Companion Dashboard

## Project Description
Golf Companion Dashboard is a an application that allows users to manage and track their golf activity in one place. The app includes features for tracking rounds, logging practice sessions, updating player information, and getting club recommendations.

## Features
- Home screen with player summary
- Profile page to save player name and favorite course
- New Round page to enter score, par, and putts
- Practice Log to record practice time
- Club Guide to suggest clubs based on distance
- Automatic round status such as under par, even par, or over par
- Practice level updates such as beginner, improving, or committed golfer
- Random course condition updates such as wet or windy
- Reset stats button
- Exit application button
